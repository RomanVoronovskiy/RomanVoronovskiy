## 👋 Обо мне

Я Java backend-разработчик и технический лидер. С 2021 года занимаюсь коммерческой backend-разработкой: FinTech, enterprise-системы, интеграционные и высоконагруженные сервисы.

Основной фокус — **Java, Spring Boot, Kafka, PostgreSQL, микросервисная архитектура, распределённые системы и production-разработка**.

Помимо разработки, преподавал Java на **Hexlet, Skypro и OTUS**. В обучении делаю упор не на пересказ документации, а на то, как Java-разработка выглядит в реальных проектах: архитектура, производительность, интеграции, отказоустойчивость, code review, системный дизайн и разбор production-кейсов.

- 🏗 Проектирование и развитие backend-сервисов
- ⚙️ Микросервисы, event-driven архитектура, Kafka
- 🐘 PostgreSQL, SQL, JPA/Hibernate и производительность
- 🔐 Keycloak, OAuth2 и backend-безопасность
- 📦 Docker, Kubernetes и CI/CD
- 📊 Prometheus, Grafana, ELK/Graylog и наблюдаемость
- 👥 Code review, менторство и развитие инженерных практик
- 🎓 Преподавание Java и подготовка разработчиков к техническим собеседованиям

## 🧩 Ежедневный алгоритмический челлендж на Java

Планирую серию ежедневных видео с последовательным разбором алгоритмических задач — **от простых к сложным**. Задача челленджа — не просто набивать решения, а научиться видеть подходы, оценивать сложность и уверенно объяснять решение на собеседовании.

Формат каждого выпуска:

1. задача и ограничения;
2. разбор идеи решения;
3. реализация на Java;
4. оценка временной и пространственной сложности;
5. альтернативные подходы;
6. типичные ошибки и вопросы, которые могут задать на собеседовании.

План движения:

`Массивы и строки → HashMap / Set → Stack / Queue → Linked List → Binary Search → Trees → Graphs → Recursion / Backtracking → Dynamic Programming`
