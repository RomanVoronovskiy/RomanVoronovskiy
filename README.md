## 👋 Обо мне

Я Java backend-разработчик и технический лидер. Шесть лет занимаюсь коммерческой разработкой: проектирую и развиваю backend-сервисы, интеграционные решения и распределённые системы для FinTech и enterprise-проектов.

Основной фокус — **Java, Spring Boot, Apache Kafka, PostgreSQL, микросервисная архитектура и production-разработка**.

Помимо разработки, преподаю Java. В обучении и менторстве делаю упор на инженерное мышление: как читать и улучшать код, находить причину проблемы, принимать архитектурные решения и объяснять их команде.

### Чем занимаюсь

- проектирование и развитие backend-сервисов;
- микросервисная и event-driven архитектура;
- интеграции и асинхронное взаимодействие через Kafka и RabbitMQ;
- работа с PostgreSQL, SQL и JPA/Hibernate;
- производительность, многопоточность и отказоустойчивость;
- backend-безопасность, OAuth2 и Keycloak;
- Docker, Kubernetes и CI/CD;
- логирование, метрики и наблюдаемость;
- code review, техническое лидерство и менторство.
